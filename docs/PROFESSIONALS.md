# Comptes professionnels — QuickAtlas

## Système actuel

Un compte peut s'inscrire comme "professionnel" (case à cocher à
l'inscription, ou activable plus tard) avec nom d'entreprise, logo et
site web optionnel.

### Paliers (basés uniquement sur le nombre d'annonces publiées)

| Palier | Seuil (annonces publiées, total cumulé) |
|---|---|
| Nouveau | 0 à 4 |
| Actif | 5 à 14 |
| Confirmé | 15 à 29 |
| Expert | 30+ |

À chaque palier franchi : **1 crédit de mise en avant gratuite** est
offert automatiquement (même système de crédits que le parrainage).

### Badge "Domaine vérifié"

Si l'email du compte partage le même domaine que le site web renseigné
(ex. `contact@monentreprise.com` + site `monentreprise.com`) → badge
affiché. Volontairement **jamais bloquant** à l'inscription — voir la
discussion dans le README sur pourquoi un email "professionnel" n'est
pas exigé (aucun moyen fiable de le vérifier techniquement).

### Où c'est affiché

- Logo + badge de palier + badge domaine vérifié : sur chaque carte
  d'annonce et sur la fiche détail
- Section "Profil professionnel" complète : page Passeport

## Ticket séparé — évolution vers un vrai score professionnel

Le système actuel est **uniquement quantitatif** (nombre d'annonces).
Une évolution est envisagée (à spécifier dans un ticket dédié, non
commencée) vers un score combinant :
- Activité (fréquence de publication, régularité)
- Qualité (taux d'annonces suspendues/signalées)
- Évaluations reçues (moyenne, nombre d'avis)
- Taux de réponse aux messages

**Non implémenté** — le système actuel (paliers par nombre d'annonces)
reste en place tel quel tant que ce ticket n'est pas spécifié plus en
détail.
