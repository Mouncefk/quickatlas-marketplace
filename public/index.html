    GUIDE

    Mode d'emploi de QuickAtlas

    Un aperçu rapide de tout ce que vous pouvez faire sur le site.

    🗺️ Premiers pas : explorer

    Cliquez sur un pays sur la carte pour découvrir ses villes, puis ses annonces. Utilisez la petite barre de recherche pour trouver directement un titre, une ville ou un pays.

    Les pilules de catégories (Immobilier, Véhicules, Mode…) vous permettent aussi de parcourir toutes les annonces d'une catégorie, dans le monde entier, sans passer par la carte.

    📝 Publier une annonce

    Depuis "Publier une annonce", choisissez une catégorie, un type (Vente, Location, Achat ou Emploi), ajoutez photo, prix et description. L'assistant IA peut rédiger le texte à votre place si vous avez configuré votre propre clé.

    Vous pouvez aussi cocher "ouvert à l'échange" pour proposer un troc plutôt qu'une vente classique. Vos annonces expirent après 60 jours et se renouvellent en un clic depuis "Mes annonces".

    💬 Acheter, négocier, échanger

    Contactez un vendeur directement depuis une annonce (messagerie interne, ou WhatsApp s'il a renseigné son numéro). Vous pouvez aussi faire une offre chiffrée ou proposer un échange, que le vendeur accepte ou refuse.

    Une fois la transaction conclue, pensez à laisser un avis au vendeur — ça aide toute la communauté.

    🔔 Rester informé

    Deux façons de ne rien rater : les favoris (retrouver une annonce précise) et les alertes (être prévenu·e des nouvelles annonces qui vous intéressent).

    1. Lancez une recherche (ville, catégorie, mot-clé) depuis "Explorer".

    2. Cliquez sur "Enregistrer cette recherche", donnez-lui un nom.

    3. Dès qu'une nouvelle annonce correspond, vous recevez un email — sans avoir à revenir vérifier vous-même.

    4. Retrouvez et gérez toutes vos alertes à tout moment dans "Alertes" (menu du haut).

    🛂 Votre profil et Passeport QuickAtlas

    La page "Passeport" regroupe vos tampons de pays (où vous avez vendu ou acheté), votre numéro WhatsApp et votre lien de parrainage — chaque personne inscrite via ce lien vous fait gagner un crédit de mise en avant gratuit.

    🔒 Sécurité et confiance

    Un badge "vendeur vérifié" apparaît quand l'email d'un membre est confirmé. Les annonces sont automatiquement passées au crible (description, photo, prix) pour repérer les signaux suspects. Vous pouvez signaler toute annonce qui vous semble problématique.

    Fonctionnalités IA

    QuickAtlas peut traduire automatiquement les annonces dans votre langue. Cette fonctionnalité est optionnelle et fonctionne avec votre propre clé API : vous gardez le contrôle total, et c'est votre fournisseur d'IA qui facture l'usage, pas QuickAtlas.

    Comment obtenir une clé API (gratuit à la création, facturé à l'usage) :

    1. Créez un compte chez un fournisseur d'IA — console.anthropic.com (Claude) ou platform.openai.com (ChatGPT).
    2. Dans la section « API Keys » de votre compte, créez une nouvelle clé.
    3. Copiez-la (elle ne s'affiche qu'une seule fois) et collez-la ci-dessous.

    Le coût d'une traduction d'annonce est minime (quelques centimes ou moins). Votre clé n'est jamais visible par les autres utilisateurs ni par les administrateurs d'QuickAtlas — elle est chiffrée et n'est utilisée que pour vos propres traductions.
